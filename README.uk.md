# Lean UI

Легкий кастомний інтерфейс інвентаря для Luanti зі слотами броні
та енциклопедією рецептів із пошуком.

## Що це

Lean UI замінює стандартне вікно інвентаря на власне, яке додає:

- **Слоти броні** (показуються тільки якщо встановлено `3d_armor`)
- **Кнопку «Рецепти»**, яка відкриває енциклопедію з пошуком
- **Категорії** (Інструменти, Броня, Світло, Руди, Їжа, Крафт, Будівництво)
- **Пагінацію** для великих списків рецептів
- **Підказки** на інгредієнтах і результатах
- **Українську та англійську локалізацію**

## Можливості

### Кастомний інвентар
- Чистий layout з сіткою крафту, головним інвентарем і hotbar
- Слоти броні з'являються автоматично, якщо виявлено `3d_armor`
- Коректно працює і без `3d_armor`

### Книга рецептів
- Пошук за назвою або описом
- Фільтр за категорією через dropdown
- Посторінковий перегляд (36 на сторінку)
- Перегляд сітки інгредієнтів
- Підказки при наведенні курсора
- Фільтри та номер сторінки зберігаються при поверненні з рецепта

### Продуктивність
- Індекс рецептів будується **один раз** при старті сервера
- Списки категорій відсортовані заздалегідь — перемикання миттєве
- Lowercase назв і описів кешується — немає повторних `:lower()`
- Жодних `globalstep`, жодної роботи на кожен кадр
- Підходить для серверів із тисячами рецептів

Перевірено на 234 рецептах: індекс будується за ~5 мс.

## Вимоги

- Luanti (Minetest) 5.8 або новіше
- Мод `default` (зазвичай входить у гру)

**Опційно:**
- `3d_armor` — вмикає слоти броні в інвентарі

## Встановлення

1. Завантажте архів із розділу Releases.
2. Розпакуйте папку `lean_ui` у директорію `mods` вашої гри:
   - `games/<назва_гри>/mods/lean_ui/`
3. Перезапустіть Luanti.

Якщо використовуєте папку `mods/` на рівні світу — покладіть туди.

## Використання

- Натисніть `i`, щоб відкрити інвентар.
- Натисніть **Рецепти**, щоб відкрити книгу.
- Використовуйте пошук або категорії.
- Клік на предмет — показує рецепт.
- **Назад** — повертає до списку (зберігає фільтри).
- **До інвентаря** або **X** — закриває.

## Локалізація

Мод містить українську (`uk`) та англійську (вбудовану) локалізації.

Щоб додати іншу мову, створіть
`lean_ui/locale/lean_ui.<мова>.tr` у форматі:

```
# textdomain: lean_ui
Recipe Book=...
Recipes=...
```

Повний список рядків — у `locale/lean_ui.uk.tr`.

## Налаштування

Константи на початку `recipes.lua`:

| Константа | За замовчуванням | Значення |
|---|---|---|
| `RESULTS_PER_PAGE` | 36 | Рецептів на сторінці |
| `COLS` | 9 | Колонок у сітці |
| `CELL` | 1.2 | Розмір іконки |
| `CELL_STEP` | 1.25 | Крок між іконками |

Координати інвентаря — в `init.lua`, у `build_inventory_formspec()`.
